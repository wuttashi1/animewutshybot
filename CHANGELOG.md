# Изменения

## 1.0.0-rc.1

Кандидат на релиз; окончательная приёмка требует проверки на Discord-сервере.

- Объединены текущий main и серверная Docker-ветка; сохранены группы команд и настройки серверов.
- Личные списки обновляются на месте; страницы и галерея повторно используют сообщения.
- Удалены секреты из Compose; ENV вынесен в отдельный файл.
- Убраны дублирующиеся slash-алиасы из стандартного набора; исправлен вызов legacy-обработчиков.
- Ограничены таймауты и повторные GET-запросы, добавлена проверка ответов API.
- Добавлена защита базы от незаметного сброса, сериализация импорта и обновления списков.
- Сохранение обновлённого Yummy-токена даже при последующем сбое получения списка.
- Автоматические подколы и фоновые импорты требуют явного включения.
- Добавлены тесты регрессий, CI и инструкции эксплуатации.
- Повторная настройка сервера не создаёт новые форумы; восстановление панелей не дублирует сообщения.
- Старые кнопки оценок и рекомендаций получают постоянные ID при запуске.
- Команды владельца проверяют Discord ID; диагностика API не отправляет попытки входа.
- Импорты одного Yummy-аккаунта сериализуются между серверами; оценка подтверждается до обновления панели.
