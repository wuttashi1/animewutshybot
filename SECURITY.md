# Безопасность

Не публикуйте токены, пароли, `.env`, базу пользователей и логи с персональными данными в issues. При обнаружении утечки сначала отзовите ключ у соответствующего провайдера.

Используйте личный канал связи с владельцем репозитория для сообщения об уязвимости. В репозитории нет заявленного SLA или программы bug bounty.

Бот хранит пользовательские Yummy-токены локально для синхронизации. Ограничьте доступ к каталогу данных и резервным копиям. Форумные списки не являются приватными Discord-каналами.
